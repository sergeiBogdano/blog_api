# Blog API

Blog API — это RESTful API для блога с поддержкой аутентификации, управления статьями, комментариями и категориями.

## Функциональность
- Регистрация и аутентификация пользователей.
- CRUD-операции для статей и комментариев.
- Управление категориями для статей.
- Админ-панель для управления пользователями, статьями и комментариями.

## Установка и запуск

### Требования
- Docker и Docker Compose
- Python 3.10+
- PostgreSQL

### Локальный запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/sergeiBogdano/blog_api.git
   cd blog_api
   ```

2. Убедитесь, что у вас установлен Python и PostgreSQL.

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```

5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

### Запуск через Docker
1. Соберите и запустите контейнеры:
   ```bash
   docker-compose up --build
   ```

2. API будет доступно по адресу: `http://localhost:8000`.

## Тестирование
1. Настройте тестовую базу данных.
2. Запустите тесты:
   ```bash
   pytest
   ```
